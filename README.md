An entry for the [Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876) bounty on make.fun: the funniest final text a dying phone sends at one percent battery, under 200 characters, in the phone's own voice.

`main.py` (stdlib only, deterministic, no network) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` and self-checks the gate (1–200 UTF-8 characters, not whitespace-only, single line).

## Entry

> 1%. Delete my search history, cancel my 6am alarm, and tell my owner I died doing what I loved: ignoring his calls.

## Run

```sh
python3 main.py
```
